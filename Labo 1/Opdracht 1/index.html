Opdracht 10

wat doen deze requests?

  • GET: vraagt gegevens op van de server.
  • POST: stuurt gegevens naar de server en wordt vaak gebruikt wanneer er iets wordt aangemaakt of gewijzigd.
  • PUT: vervangt of wijzigt een volledige resource.
  • PATCH: wijzigt slechts een deel van een resource.
  • DELETE: verwijdert een resource.
  • HEAD: werkt zoals GET, maar vraagt alleen de headers op en niet de response body.
  • CONNECT: maakt een tunnelverbinding met een server.
  • TRACE: wordt gebruikt om de weg van een request te testen.

GET wordt gebruikt om informatie van een server op te vragen. Een GET-request hoort alleen gegevens te lezen en mag volgens de HTTP-semantiek geen belangrijke wijziging op de server veroorzaken.

POST wordt gebruikt om gegevens naar de server te sturen. Bijvoorbeeld bij het verzenden van een formulier, het aanmaken van een account of het plaatsen van een bestelling. Een POST-request kan dus wel een wijziging op de server veroorzaken.
